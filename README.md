## 🎮 Sobre o jogo

Um jogo simples de **pedra, papel ou tesoura**, feito em Python para praticar lógica de programação. Escolha sua jogada e enfrente o computador, que seleciona uma opção aleatoriamente.

## 🕹️ Como jogar

No menu, escolha uma opção:

- `1` — Jogar uma rodada
- `2` — Sair do jogo

Durante a rodada, digite `pedra`, `papel` ou `tesoura`. O jogo mostra a escolha do computador e informa se você venceu, perdeu ou empatou.

## 📜 Regras

- Pedra vence tesoura.
- Tesoura vence papel.
- Papel vence pedra.
- Escolhas iguais resultam em empate.

## ▶️ Como executar

É necessário ter o **Python 3** instalado. Salve o código em um arquivo, por exemplo `jokenpo.py`, e execute no terminal:

```bash
python jokenpo.py
